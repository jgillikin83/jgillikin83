Getting Started

  • Click "New Page" to create your first wiki page
  • Use Markdown syntax for formatting your content
  • Search through all your pages using the search box
  • Edit any page by clicking the "Edit" button

Markdown Syntax

You can use standard Markdown syntax to format your pages:

  • # Heading 1 for main headings
  • ## Heading 2 for sub headings
  • **bold text** for bold text
  • *italic text* for italic text
  • [link text](url) for links
  • - item for bullet lists
  • 1. item for numbered lists
