Markdown Syntax Help

You can use the following Markdown syntax to format your page:

  • # Main Heading - Creates a large heading
  • ## Sub Heading - Creates a smaller heading
  • **bold text** - Makes text bold
  • *italic text* - Makes text italic
  • [Link Text](http://example.com) - Creates a link
  • - List item - Creates a bullet point
  • 1. Numbered item - Creates a numbered list
  • `code` - Formats text as code
  • > Quote - Creates a blockquote
